Per-page transcription and queue. Resolved decision 5: a page becomes reviewable and editable as soon as its own draft completes while later pages keep processing. The canonical list keeps Date · Name · Status rows searchable, sortable, and paginated at 10 rows, with Review now only for completed pages. Persisted page names come from server PageSummary.label values such as “Maya Rodriguez · Page 1”, never browser filenames.
Document gate. Until every page completes, the document has no review state — only mixed processing counts. It can enter Needs review only after full completion; Ready to grade still requires full-document teacher review (resolved decision 5).
One ordered draft. PRD §4: each document has one editable ordered draft; paragraphs, lists, line breaks and math are preserved best-effort.
Source-first fallback. Principle 4: untranscribable content falls back to the source image — it is never silently invented or omitted.
