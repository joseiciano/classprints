The gate is a state, not a place. Mark graded is available only when the document is reviewed (Ready to grade) — a state requirement, not a change of place (PRD §5, decision 5). Before that, the rail shows the commitment locked with its reason.
Score rules. Up to two decimals; values above the assignment maximum are rejected with a clear error; display is “8.5 / 10” when a max is defined and the value alone otherwise — no percentage conversion (decision 4). The maximum itself is assignment metadata, updated with PATCH /assignments/:assignmentId, not a grading command.
Grading is the teacher's judgment. Submission score and comments attach to the submission, never to the transcription; per-question judgments and awarded points remain separate, with no automatic assessment in this release (PRD §6, persona 3).
