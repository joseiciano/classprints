Materials are context, not student work. The teacher authors one document per assignment; it is never a submission and never graded, and it is excluded from all grading counts (PRD §2, §6, principle 5). Hence the stamp.
"Open materials" shows the source. The button opens the materials document — the pages used to create the assignment — in the same side-by-side workspace (PRD §2). Replacement creates a new version while earlier versions remain available read-only; retranscription never silently overwrites teacher edits (resolved decisions 6 and 8).
Deletion is scoped, never silent. A page, the materials document, or an entire submission can each be deleted; deleting a class or assignment cascades to everything inside it (PRD resolved decision 3).

Submissions exist on their own. A submission can be created for any student whether or not the assignment has materials at all (PRD §3) — Noah's row exists with nothing transcribed and no context document required.
States are per page, then per submission. Each page carries its own state and completes independently (PRD resolved decision 5): Maya's p1 and p2 are complete while p3 is still transcribing, so her row shows only the processing state and page count. The document gets a review state only after every page completes.
One review state, then grading. "Ready to grade" replaces "Ready" — it is the reviewed-and-awaiting-grading state, so no redundant "Ready" chip (PRD review state). "Error" names system upload/parsing failures, distinct from grading outcomes (PRD processing state). Scores show against the assignment max (decision 4).
Rows open the document. The canonical list opens a submission from its row, while direct actions preserve the available workflow — Grade, View, Return to Needs review, Review error, and Create submission (PRD §3, §5, §6).
