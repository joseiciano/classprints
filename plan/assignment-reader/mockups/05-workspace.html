Maximum score — set or change the upper bound here; scores above it are rejected

One control: press Grade to set the graded state, press again to sunset it and return the submission to Ready. Score and comments are both optional.

The gate is a state, not a place. Grade unlocks only at Ready, and Ready requires review of the full document (PRD §5, decision 5). Before that, the rail shows the commitment locked with its reason.
Score rules. Up to two decimals; values above the assignment maximum are rejected with a clear error; display is “8.5 / 10” when a max is defined and the value alone otherwise — no percentage conversion (decision 4).
Grading is the teacher's judgment. Score and comments attach to the submission, never to the transcription; no automatic assessment in this release (PRD §6, persona 3). Grade is one toggle — press to set the graded state, press again to sunset it; a sunset submission stops appearing as graded.
