The canonical list component. Columns are Date · Assignment · Status (one state chip: "Need review" while any work is ungraded, "Graded" when fully reviewed — no per-state radio chips). Headers sort ascending/descending on click, the connected search filters by any column, and the list paginates at 10 rows. Row click opens the assignment. The same component serves Seating Charts (Date · Class · Student Count), the Classes list, Submissions, and Processing pages.
Maximum score is optional and enforced when present. Scores accept up to two decimal places; values above the maximum are rejected with a clear error, and no percentage is calculated (resolved decision 4).
Errors are system failures, not student outcomes. The Error state covers upload and parsing failures for a page or document; repair stays scoped to the failed page (PRD §2/§3; resolved decision 6).
