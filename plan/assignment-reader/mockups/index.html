How to read these wireframes
Numbered notes are the annotations. Every screen carries numbered callouts (data-n) citing the PRD capability, principle, or resolved decision behind the element — e.g. "decision 5: a page becomes reviewable as soon as its own draft completes".
Stamps mark document identity. Context · not graded marks teacher-authored assignment materials wherever they appear; student work is stamped green. PRD principle 5: context and evidence must never be conflated.
Sample content is one canonical scenario (see legend below) so states stay comparable across screens — Maya's 3-page submission is mid-transcription on every screen that shows it.

Processing — both doc types, per page
Uploading→ Queued→ Transcribing→ Completed

Runs page by page — each page carries its own state; a completed page is reviewable while siblings process. Failed ⇒ retry page (default) or confirmed whole-document retranscription.

Review — both doc types
Needs review→ Ready

Teacher-verified against the original. Materials end here: verified context. Can return to Needs review at any point.

Grading — submissions only
Not graded→ Graded

Teacher-visible path on one workspace: Needs review → Ready → Graded. Score optional, ≤ max when defined, two decimals. Returned submissions stop appearing graded.
