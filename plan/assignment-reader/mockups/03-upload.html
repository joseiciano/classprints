One standard image format. HEIC is accepted, then normalized to JPEG server-side so the workspace and transcription provider receive one standard format (resolved decision 1).
PDF is rejected this release. Rasterization and multi-page import conflict with the photograph-and-order model (resolved decision 1 rationale).
The same limits apply to both document types. Each material or submission document allows 20 pages, with a 10 MB maximum for each image (resolved decision 2).
Repair only the failed page. Oversized or failed pages can be retried or replaced without recreating the assignment or the rest of its document (PRD §2/§3).
